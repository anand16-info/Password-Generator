# 🔐 Password Generator

A simple and clean password generator web application built using **HTML, CSS, and JavaScript**.  
It allows users to generate strong and secure passwords based on selected criteria.

---

## 🚀 Live Demo
👉 https://anand16-info.github.io/Password-Generator/

---

## 📌 Features
- Adjustable password length using a slider  
- Option to include:
  - Uppercase letters  
  - Lowercase letters  
  - Numbers  
  - Symbols  
- One-click password generation  
- Copy password to clipboard  
- Clean and responsive UI  

---

## 🛠️ Tech Stack
- HTML  
- CSS  
- JavaScript

## ⚙️ How It Works
1. Select the password length using the slider  
2. Choose the character types you want  
3. Click on **Generate Password**  
4. Copy the generated password using the **Copy** button
